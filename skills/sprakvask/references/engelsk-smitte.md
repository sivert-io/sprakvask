# Engelsk smitte

Hva som avslører at en norsk tekst er tenkt på engelsk. Les denne når
teksten er skrevet av en maskin, oversatt eller skrevet av en som leser mest
engelsk.

Mye av dette er ikke *feil* i streng forstand. Det er riktige ord satt sammen
slik ingen nordmann ville gjort det – og derfor lett å kjenne igjen for
leseren, men vanskelig å se for den som skriver. Språkrådets holdning er at
lån er nyttige når norsk mangler ord, og uheldige når vi har gode ord fra før.

## Tegn og formater

| Engelsk vane | Norsk |
| --- | --- |
| em-strek `—` | tankestrek `–` med mellomrom |
| `"sitat"` | `«sitat»` |
| `Sivert's`, `NRK's` | `Siverts`, `NRKs` |
| `pc'en`, `app'en` | `pc-en`, `appen` |
| `1,000` / `3.5` | `1 000` / `3,5` |
| `10/16/2026` | `16.10.2026` |
| `9:00 AM` | `kl. 09.00` eller `kl. 09:00` |
| `Meld Deg På` (Title Case) | `Meld deg på` |
| `Du`, `Deg` med stor forbokstav | `du`, `deg` |
| `Norsk`, `Nordmann` midt i setningen | `norsk`, `nordmann` |
| komma foran `og` i oppramsing | ikke komma |
| `Hei Anna,` | `Hei, Anna` |
| mellomrom foran `?` og `!` | ikke mellomrom |

«Vennligst» er ikke feil, men det er `please` i norsk drakt og virker stivt.
Høfligheten ligger i setningen, ikke i et ord foran den.

## Grammatikk som følger engelsk

- **Yrke uten artikkel:** ✗ `Hun er en utvikler.` → ✓ `Hun er utvikler.`
- **`heller ikke`**, ikke `også ikke`.
- **`sin`, ikke `deres`, om subjektet:** ✗ `De tok med deres egne pc-er.`
  → ✓ `De tok med sine egne pc-er.`
- **Preposisjoner:** `kommentere` (ikke `kommentere på`), `insistere på at`,
  `usikker på om`, `ha en tendens til å`, `etter min mening` (ikke `i min
  mening`), `lojal mot`, `laget av`, `tanken på`.
- **Ikke `av` som engelsk *of*:** ✗ `innbyggerne av Norge` → ✓ `innbyggerne
  i Norge`.
- **Superlativ om to:** `Hvilken er best, A eller B?`
- **Entall om det hver har én av:** ✗ `De ristet på hodene sine` → ✓ `De
  ristet på hodet`. Se [grammatikk.md](grammatikk.md).
- **Foranstilt eiendomsord** er engelsk rytme. ✗ `din konto` → ✓ `kontoen
  din`. Foranstilt er ikke feil, men gir trykk på eieren.
- **`Ved + substantiv`** skjuler hvem som gjør hva: ✗ `Ved innlogging må du
  …` → ✓ `Når du logger inn, må du …`. `Ved å + infinitiv` er derimot god
  norsk: `Ved å trykke på knappen godtar du vilkårene.` (Uten komma.)

## Lånord som har kommet for å bli

Noen lånord er normert og helt i orden: `app`, `blogg`, `jobb`, `lunsj`,
`quiz`/`kviss`, `podkast`, `coach` (i arbeidslivet), `server`, `e-sport`. De
bøyes som norske ord:

- `en app – appen – apper – appene` (ikke `apps`)
- `quizen – quizer`, `workshopen – workshoper`
- Ingen apostrof foran bøyningsendelsen: `appen`, ikke `app'en`
- `klikke på` er like riktig som `trykke på`

Sammensetninger med engelske ord skrives i ett: `webdesign`, `talkshow`,
`casestudie`. Med varemerker: `Teams-møte`, `Vipps-betaling`.

## Særskriving etter engelsk mønster

Engelsk skriver sammensetninger i to ord. Norsk gjør ikke.

| Engelsk | Feil norsk | Riktig |
| --- | --- | --- |
| user name | bruker navn | brukernavn |
| sign-up form | påmeldings skjema | påmeldingsskjema |
| game night | spill kveld | spillkveld |
| two-factor authentication | to faktor autentisering | tofaktorautentisering |
| senior developer | senior utvikler | seniorutvikler |

## Punktlister og overskrifter

Engelske maler setter kolon foran hver liste og punktum etter hvert punkt,
og har Title Case i overskriftene. På norsk: ikke kolon når punktene
fortsetter setningen, ingen tegn etter korte punkter og stor forbokstav
bare i første ord. Se [tegnsetting.md](tegnsetting.md).

## Passiv

Engelsk fagtekst har mye passiv, og oversatt norsk arver den. Si hvem som
gjør hva:

> ✗ Påmeldingen vil bli behandlet innen tre dager.
> ✓ Vi svarer innen tre dager.

Se [klarspraak.md](klarspraak.md).
