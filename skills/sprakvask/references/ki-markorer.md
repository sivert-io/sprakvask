# KI-preg

Tekst fra språkmodeller har kjennetegn som leserne lærer seg å se. Noen er
feil, andre er stil. Begge deler gjør at leseren slutter å stole på teksten.

## Det Språkrådet fant

Språkrådet lot ChatGPT skrive sakprosa og fortellinger på bokmål og nynorsk
høsten 2024, og språkvaskere gikk gjennom resultatet
([«KI-språkets fallgruver»](https://sprakradet.no/aktuelt/ki-sprakets-fallgruver/),
januar 2025):

- **Bokmål: 2,6 feil per side.** 70 prosent var tegnsetting eller stor og
  liten forbokstav. Det er de to områdene å sjekke først.
- **Nynorsk: 8 feil per side**, mest gale bøyingsformer og bokmålsord som ikke
  finnes i nynorsk. Se [nynorsk.md](nynorsk.md).
- **Formene veksler.** Modellen skriver `stein` og `sten`, `vart` og `blei` –
  og a- og e-infinitiv – i samme tekst. Velg én form per ord og hold deg til
  den.
- **Formene er konservative.** `frem`, `fremtiden`, `jakken`, `sitt liv`. Det
  er ikke feil, men velg det teksten eller prosjektet ellers bruker – og legg
  eiendomsordet etter substantivet: `livet sitt`.
- **Engelsk skinner gjennom:** `tok et øyeblikk før hun svarte`, `møtte ham i
  person`, `vokste opp i Bergen, Norge`. Se [engelsk-smitte.md](engelsk-smitte.md).

## Oppblåste ord

De fleste er vanlige ord. Problemet er at de står der det ikke er noe konkret
å si. Test: Kan du si hva ordet betyr akkurat her? Hvis ikke, stryk det eller
skriv det konkrete.

| Ord | Skriv heller |
| --- | --- |
| `banebrytende`, `revolusjonerende`, `innovativ` | hva som er nytt |
| `sømløs` | hva brukeren slipper |
| `robust`, `helhetlig`, `holistisk` | hva det tåler eller dekker |
| `kraftig`, `avansert` | hva det kan |
| `skreddersydd`, `unik` | hva som er tilpasset, og til hvem |
| `spiller en avgjørende rolle` | hva det gjør |
| `et viktig steg på veien` | hva som er gjort |
| `muliggjør`, `tilrettelegger for` | hva som skjer |
| `effektivisere` | hva som går raskere, og hvor mye |
| `økosystem`, `landskap` | marked, bransje, verktøyene |

## Oversatte favorittord

Engelske ord språkmodeller bruker mye, oversatt ord for ord:

| Engelsk | Oversatt | Norsk |
| --- | --- | --- |
| delve into | dykke ned i | gå rett på innholdet |
| leverage | utnytte, dra nytte av | bruke |
| navigate | navigere | håndtere, finne fram i |
| foster | fremme | si hva dere gjør |
| streamline | effektivisere | si hva som blir enklere |
| orchestrate | orkestrere | styre, koordinere |
| underscore | understreke | si poenget |
| crucial | avgjørende | si hvorfor det er viktig |
| empower | styrke, gi makt | si hva folk kan gjøre nå |
| game changer | en game changer | si hva som endres |
| bridge the gap | bygge bro | si hva som kobles sammen |

## Innledninger og avslutninger som ikke sier noe

Stryk dem, og begynn med poenget:

- `Det er verdt å merke seg at …`, `Det er viktig å påpeke at …`
- `La oss se nærmere på …`, `La oss dykke ned i …`
- `I denne artikkelen skal vi …`
- `I en verden der …`, `I dagens digitale landskap …`
- `Kort oppsummert …`, `Avslutningsvis …`, `Alt i alt …`
- `Håper dette var nyttig!`, `Ikke nøl med å ta kontakt.`

Den siste kan byttes med noe leseren kan bruke: `Har du spørsmål, svarer vi
på post@eksempel.no.`

## Mønstre

- **Oppsummering til slutt** som gjentar det leseren nettopp har lest. Stryk
  hele avsnittet.
- **Tretall overalt:** tre adjektiver (`rask, enkel og trygg`), tre punkter,
  tre eksempler. Ta med det som er sant, ikke det som gir rytme.
- **Tvungen balanse:** `Begge alternativene har sine fordeler og ulemper` når
  det ene er klart bedre. Si hvilket.
- **`Det er ikke bare X – det er Y`.** Si hva det er.
- **Retoriske spørsmål** som overskrift eller innledning: `Hvorfor er dette
  viktig?` Si hvorfor.
- **Setninger som bare bekrefter forrige setning:** `Derfor er sikkerhet så
  viktig.`
- **Forklaringer av det leseren allerede vet.**
- **Lik rytme:** alle avsnitt like lange, alle setninger bygd over samme lest.
  (Punktlister skal ha samme grammatiske form i hvert punkt – det er noe
  annet.)

## Formatering

- **Kolon i hver overskrift:** `Sikkerhet: Slik beskytter vi dataene dine`
  → `Slik beskytter vi dataene dine`.
- **Fet skrift på annethvert uttrykk.** Uthev det ene leseren ikke må gå glipp
  av.
- **Emoji** som punktmarkører og i overskrifter.
- **En overskrift over hvert avsnitt**, også når teksten er kort.
- Em-strek og Title Case – se sjekk 1 og 4 i SKILL.md.

## Tone

- **Ikke selg.** `Vi er stolte av å kunne tilby en sømløs betalingsopplevelse`
  → `Nå kan du betale med Vipps.`
- **Ikke vær overivrig.** Utropstegn, `Flott!` og `Godt spørsmål!` hører ikke
  hjemme i vanlig tekst.
- **Ikke vær for formell heller.** KI-norsk blir ofte stiv: `benytte`,
  `foreta`, `hvorvidt`, `i henhold til`. Se [klarspraak.md](klarspraak.md).
- Skriv som til en kollega som har dårlig tid.

## Til den som vasker

Dette er stilråd, ikke rettskriving. Et ord fra tabellene er ikke feil i seg
selv – `robust` er et presist ord om programvare som tåler feil. Spørsmålet er
alltid om ordet sier noe akkurat her.
