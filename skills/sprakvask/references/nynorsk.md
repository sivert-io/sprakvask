# Nynorsk

Norge har to skriftlige målformer, og begge er offisielle. Skriver du nynorsk,
gjelder alt i de andre filene – tegnsetting, tall, datoer, klarspråk – på samme
måte. Det som skiller er formverket.

**Bland aldri de to i samme tekst.** Det er den eneste regelen som gjelder
uansett.

## Vanlige forskjeller

| Bokmål | Nynorsk |
| --- | --- |
| jeg / meg | eg / meg |
| ikke | ikkje |
| noe / noen | noko / nokon |
| hva | kva |
| hvem | kven |
| hvilken | kva for ein |
| hvordan | korleis |
| hvorfor | kvifor |
| språk | språk |
| mye | mykje |
| fra | frå |
| etter | etter |
| være | vere / vera |
| ha | ha |
| skje | skje / hende |
| bruke | bruke / nytte |

## Former som ofte glipper

**Substantiv i bestemt form flertall** ender på `-ane`/`-ene`/`-a`, ikke alltid
`-ene`:

> bokmål: `bilene`, `husene`, `jentene`
> nynorsk: `bilane`, `husa`, `jentene`

**Hokjønn er obligatorisk** i nynorsk. `ei bok – boka`, ikke `en bok – boken`.

**Passiv med `-ast`**, ikke `-es`: `det seiast` framfor `det sies`. Men se
[klarspraak.md](klarspraak.md) – aktiv er som regel bedre uansett målform.

**Ingen `-het`-ord.** Nynorsk bygger med `-leik`, `-dom`, `-skap` eller skriver
om: `moglegheit` er tillate, men `høve` er betre.

## Når du er i tvil

Slå opp i [Nynorskordboka](https://ordbokene.no). Nynorsk har flere valgfrie
former enn bokmål, og flere av dem er like riktige – men vær konsekvent
innenfor samme tekst.

## Til den som vasker

Er teksten allerede på nynorsk, skal den bli værende på nynorsk. Ikke
«normaliser» til bokmål fordi det er den vanligste målforma. Det er å bytte ut
forfatterens språk, ikke å vaske det.
