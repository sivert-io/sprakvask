# Ordvalg og former

## Særskriving

Den vanligste og mest meningsbærende feilen i norsk. Sammensatte ord skrives i
**ett** ord.

| Feil | Riktig | Hva det feilaktige betyr |
| --- | --- | --- |
| `lørdags kvelden` | `lørdagskvelden` | – |
| `data spill` | `dataspill` | – |
| `røyk fritt` | `røykfritt` | «røyk, fritt!» |
| `stekt kylling lever` | `stekt kyllinglever` | at kyllingen lever |
| `påmeldings frist` | `påmeldingsfrist` | – |

Blir ordet uleselig langt, kan du sette bindestrek – ikke mellomrom:
`arrangements-gjennomføring`. Men som regel er det bedre å skrive om.

## Og / å

- **og** binder sammen: `spise og drikke`
- **å** står foran infinitiv: `å spise`

Test: kan du bytte ut med «samt», er det `og`. Kan du sette «for å» foran, er
det `å`.

## De / dem

- **de** er subjekt: `De kommer i morgen.`
- **dem** er objekt: `Vi inviterte dem.`

Test: bytt med «he/him» på engelsk, eller med «vi/oss».

## Sin / hans / hennes

**sin** viser tilbake til subjektet i samme setning:

> Ola tok med seg **sin** egen PC. (Olas PC)
> Ola tok med seg **hans** PC. (en annens PC)

Dette er en betydningsforskjell, ikke en stilforskjell.

## Vanlige forvekslinger

| | |
| --- | --- |
| `enn` / `ennå` | sammenlikning / tid |
| `da` / `når` | én gang i fortid / gjentakelse eller framtid |
| `hvem` / `hvem sin` | «hvems» finnes ikke |
| `i forhold til` | brukes altfor bredt. Ofte: `sammenliknet med`, `når det gjelder`, `for` |
| `i henhold til` | stivt. Ofte: `etter`, `ifølge` |
| `ifht.` / `mtp.` | skriv det ut |

## «Da» og «når»

> **Da** vi åpnet dørene, var køen lang. (én gang, fortid)
> **Når** vi åpner dørene, slipper vi inn ti om gangen. (framtid eller gjentakelse)

## Ord som ikke bør brukes i grensesnitt

| Unngå | Bruk heller |
| --- | --- |
| `vennligst` | ingenting, eller skriv om setningen |
| `benytte` | `bruke` |
| `foreta` | `gjøre` |
| `vedrørende` | `om` |
| `således` | `slik` |
| `i den hensikt å` | `for å` |
| `pr.` | `per` |
