# Forkortelser

## Reglene

- **Bruk bare forkortelser leseren forstår.** I løpende tekst, og særlig i
  grensesnitt, er det som regel bedre å skrive ordet ut. Forkortelser hører
  hjemme der plassen er trang: tabeller, parenteser, fotnoter.
- **Hovedregelen er punktum:** `f.eks.`, `bl.a.`, `ca.`, `nr.`, `tlf.`
- **Ikke punktum** i initialord (`NRK`, `EU`, `AS`) og i forkortelser for
  mynt, mål og vekt (`kr`, `km`, `kg`, `min`, `cm`).
- **Ikke mellomrom inni** en forkortelse: `f.eks.`, `t.o.m.`, `m.m.`
- Noen har bare ett punktum til slutt: `osv.`, `pga.`, `mht.`, `vha.`,
  `mva.`, `ift.`, `ifm.`, `iht.`, `mtp.`
- **Aldri to punktum.** Slutter setningen med en forkortelse, er
  forkortelsespunktumet nok: `… mat, drikke osv.`

## Initialord

- Egennavn som leses bokstav for bokstav, skrives med store bokstaver: `NRK`,
  `FN`, `EU`. Firmaer og organisasjoner bestemmer selv over sitt eget navn.
- Egennavn som leses som ord, kan skrives med små eller store. Språkrådet
  anbefaler små: `Nato`, `Unesco`.
- Vanlige ord kan også skrives med små, og det anbefales: `pc`, `tv`, `cd`,
  `wc`, `sms`. `PC`, `TV` er ikke feil.
- Noen skrives alltid med store: `AS`, `PIN`, `ISBN`.
- **Bøyning og sammensetning med bindestrek:** `pc-en`, `pc-er`, `sms-en`,
  `EU-land`, `tv-program`, `e-ID`. Ikke apostrof (`pc'en`) og ikke tett
  (`pcen`).
- **Eiendomsform med liten s, uten apostrof:** `NRKs`, `EUs`, `Natos`.
- Initialord som har blitt vanlige ord, bøyes og settes sammen som andre ord:
  `aids`, `hiv`, `laser`, `radar` → `hivtest`, `laserskriver`.

## Vanlige feil

| Feil | Riktig | Merk |
| --- | --- | --- |
| `evt.` | `ev.` | `evt.` betyr «etter vår tidsregning» |
| `ifht.` | `ift.` | i forhold til |
| `ifb.` | `ifm.` | i forbindelse med (endret 2022) |
| `mnd.` | `md.` | måned, både entall og flertall |
| `etc.` | `osv.` | |
| `kfr.` | `jf.` | jamfør |
| `s.k.` | `såk.` | såkalt |
| `att.` | `til`, `ved` | |
| `c.c.` | `kopi til` | |
| `c/o` | `adr.` | |
| `ex.`, `ekspl.` | `eks.` | eksempel, eksemplar |
| `gt.` | `g.` | gate |
| `Mvh` | `Mvh.` – eller skriv ut | se [e-post-og-brev.md](e-post-og-brev.md) |

`mtp.`, `ang.` og `vedr.` er gyldige forkortelser. I løpende tekst er det
likevel bedre å skrive `med tanke på` og `om`.

Ukedager: `ma.`, `ti.`, `on.`, `to.`, `fr.`, `lø.`, `sø.` (nynorsk `må.`,
`ty.`, `on.`, `to.`, `fr.`, `lau.`, `su.`).

Enheter uten punktum: `kr`, `km`, `m`, `cm`, `mm`, `kg`, `g`, `l`, `dl`,
`min`, `s`, `t` (time), `km/t`, `kvm` eller `m²`, `kB`, `MB`, `GB`.

Stortingsdokumenter fra 2009–2010 og senere: `Meld. St.`, `Prop. 1 S`,
`Prop. 4 L` – ikke `St.meld.` og `St.prp.`
