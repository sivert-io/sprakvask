# Grammatikk og bøyning

## Adjektiv og samsvar

**Flertall etter `er`, `var` og `blir` får -e:**

> `Vi er enige.` · `Deltakerne var fornøyde.` · `Plassene er ledige.`

Med preposisjon etter er -e valgfritt: `fornøyd(e) med`, `enig(e) i`. Faste
vendinger kan stå ubøyd: `De er glad i hverandre`, `Alle er velkommen`
(eller `velkomne`).

**Partisipp etter `er`/`blir` står ofte ubøyd:** `Temperaturene er uendret.`,
`Bøkene er trykt i år.`, `Linjene er opptatt.`

**Intetkjønn:**

- `grønt hydrogen` (ikke `grønn hydrogen`), `et stort rom`
- `et glad barn` (ikke `gladt`), `et norsk firma` (ikke `norskt`)
- `bra` bøyes ikke: `bra folk` (ikke `brae`)

**Adverb foran partisipp har ingen -e:** `fast ansatte`, `midlertidig
ansatte`, `offentlig ansatte`, `selvstendig næringsdrivende`.

**`denne typen`** om én type, uansett hvor mange tingene er: `denne typen
feil` (ikke `disse typer feil`).

## Partisipp av sterke verb

Bestemt form og flertall ender på `-ne`:

> `den skrevne teksten` · `stjålne sykler` · `den forsvunne filen` ·
> `funne gjenstander`

Ikke `skrevede`, `forsvunnede`, `funnede`. Om trykksaker: `boka er trykt`,
ikke `trykket`.

## Verb

| Riktig | Ikke | Merk |
| --- | --- | --- |
| `vi satte oss ned` | `vi satt oss ned` | `sette – satte – har satt` |
| `huset brant` | `huset brente` | `brant` uten objekt |
| `hun brente papirene`, `hun brente seg` | `brant seg` | `brente` med objekt |
| `jakka hang` / `hun hengte opp jakka` | | samme mønster |
| `å synes` | `å syns` | presens `synes`/`syns`, perfektum `har syntes` |
| `lykkes – lyktes – har lyktes` | | også `har lykkes` |
| `gis`, `fås`, `tas`, `nås` | `gies`, `fåes`, `taes` | |
| `har knekt` | `har knukket` | |
| `har gjeldt` | `har gjeldet` | `gjeldet` = kastrert |
| `prisen har økt` | `prisen er økt` | `er økt` leses som passiv |

**Imperativ** er infinitiv uten -e: `Prøv`, `Send`, `Kom`, `Registrer`,
`Kvitter` – uten aksent. Ender stammen på en tung konsonantgruppe, går
begge: `Åpne`/`Åpn`, `Endre`/`Endr`. På knapper leses `Åpne` og `Endre`
lettest.

**`å ikke`** er greit: `Husk å ikke dele passordet.` Korte adverb kan stå
mellom `å` og verbet, lange innskudd bør unngås.

## Substantiv

| Riktig | Ikke |
| --- | --- |
| `én prosent`, `prosenten` | `ett prosent` |
| `et medium – mediet – medier – mediene` | `et medie` |
| `i mediene`, `i sosiale medier` | `i media`, `i sosiale media` |
| `et potensial` | `et potensiale` |
| `museet`, `mediet` | `museumet` |
| `risikoer`, `saldoer`, `kontoer` (eller `konti`) | `risiki`, `saldi` |
| `en parameter – parametere` (eller `parametre`) | |
| `i finansverdenen` | `i finansverden` |
| `apper`, `quizer`, `workshoper` | engelsk `-s` i flertall |

**-ing eller -sjon:** `-ing` om prosessen, `-sjon` om resultatet eller
fagbegrepet: `organisering` / `organisasjon`. Der det ikke er noen
forskjell, velg `-ing`: `implementering`, `delegering`, `automatisering`.

**-ing eller -else:** mange par er likestilte (`utdanning`/`utdannelse`).
Velg én, og hold deg til den gjennom teksten.

**Norsk bruker entall om det hver har én av:**

- ✗ `Deltakerne ristet på hodene sine.` → ✓ `Deltakerne ristet på hodet.`
- ✗ `De mistet jobbene sine.` → ✓ `De mistet jobben.`
- `livet` står i entall i faste uttrykk: `mistet livet`, `endret livet`.

## Eiendomsform

- `Olas pc` eller `pc-en til Ola`. Genitiv med preposisjon er ofte
  naturligst: `bilen til Per`, `styret i foreningen`.
- Felles eie er tydeligst med preposisjon: `hytta til Per og Pål`. Hver sin:
  `Ibsens og Bjørnsons verker` (ikke `Ibsen og Bjørnsons verker`).
- Ingen genitiv på lovtitler: `angrerettloven § 22`.

## Pronomen

- `man` og `en` er like riktige. Objektsformen er alltid `en` og eieformen
  `ens`. Ikke bland `man` og `en` i samme tekst. I tekst til leseren: skriv
  heller `du`.
- **`hen`** står i rettskrivingen fra 2022, både generelt og om personer som
  ikke vil kalles `han` eller `hun`. Er kjønnet ukjent, anbefaler Språkrådet
  `hun eller han` / `han eller hun`, flertall eller omskriving.
  Aldri `den` om en person.
- `Kari og jeg var der` (subjekt) – ikke `Meg og Kari var der`. Objekt:
  `Hun inviterte Kari og meg`.
- `seg` må være med der verbet krever det: `konsentrere seg`. Men ikke
  `selv` på slump: ✗ `uttrykke seg selv` → ✓ `uttrykke seg`.

## Konsekvens

Bokmål har mange valgfrie former. Det er ikke feil å velge noen av dem, men
det er feil å veksle innenfor samme tekst.

- **a-endelser:** `boka` eller `boken`, men samme ord skal ha samme form hele
  veien. Ikke `ei bok – boken`.
- **Doble former:** `frem`/`fram`, `hvis`/`viss`, `deltaker`/`deltager`,
  `forskning`/`forsking`, `annen`/`andre` som ordenstall.
- **Samme ord for samme ting.** Heter det `påmelding` ett sted, skal det ikke
  hete `registrering` et annet – leseren tror det er to forskjellige ting.

## Ordstilling

- Verbet står på plass nummer to i helsetninger: `I morgen åpner vi
  påmeldingen.` (ikke `I morgen vi åpner`).
- I leddsetninger står `ikke` foran verbet: `… fordi vi ikke har fått
  svar`.
- `Vi trodde alle …`, ikke `Vi alle trodde …`
- `heller ikke`, ikke `også ikke`.
- Yrke uten artikkel: `Hun er utvikler.` (Med adjektiv: `en dyktig
  utvikler`.)

## Passiv

Bokmål har både s-passiv (`sendes`) og bli-passiv (`blir sendt`). Aktiv er
som regel bedre – se [klarspraak.md](klarspraak.md). Nynorsk har egne regler
for passiv – se [nynorsk.md](nynorsk.md).
